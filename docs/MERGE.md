## 验证与限制

合并后重新运行：App 32 项测试通过，网络 33 项测试通过，Ruff、JavaScript 语法和 wheel/sdist 构建通过。网络测试绑定本机回环端口，沙箱内受限时已在获批环境复测通过，没有连接机器人或外网。另扩展特殊字符 SSID 回归，先确认冒号/反斜杠失配，再关闭 nmcli 默认转义，全部通过。

`scripts/check_release.py` 检查发布包保留全部许可且排除常见私有媒体/配置格式；同时使用错误媒体/清单样例验证其拒绝行为。它不构成通用秘密扫描器。上传候选文件另检查个人路径、真实网络标识及已知凭据模式；主应用源文件、前端和原 32 项测试与来源提交逐字节相同。GitHub Actions 执行相同核心检查，远程运行结果单独确认。

合并前进行独立只读复核；发现的 SSID 转义问题已修复并复核，未发现剩余 P0/P1/P2 问题。该检查不涉及其他项目、生产服务器或真实私有素材。

原 App 验证记录见 [VALIDATION.md](VALIDATION.md)；网络原型的硬件经验不能替代通用公开版验收。完整游戏、语音识别、生成式对话及机器人动作未实现；合并源码没有将 App 安装到真实 Wireless，也没有改变机器人当前网络配置。

首次 GitHub CI 暴露干净 Linux 缺少 Cairo / GObject 编译依赖，已在 runner 补系统依赖，不改变应用依赖版本或跳过安装。Python 3.14 两项测试的上游拦截安装过晚；用连接后强制 20 ms 调度让步重现后，把拦截移到客户端连接前，并让客户端显式使用未被替换的连接器。两项强制调度测试与原 33 项均通过。关闭连接允许 TCP FIN 或 RST，但超时和收到数据仍视为失败；未修改中继运行时代码。
